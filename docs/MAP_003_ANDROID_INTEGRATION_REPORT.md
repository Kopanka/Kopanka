## 2026-11-26 — MAP-003A: unified PNG renderer for 512×512 test world

**Мета:** усунути підтверджений тестом Android 0.3.1 різкий прямолінійний стик між PNG-сценою 32×32 та плоскими procedural placeholders за її межами, а також видиму логічну сітку.

**Вхідні матеріали:** останній код draft PR #10, арт-пакет MAP-003 v1.4 (62 PNG), скриншот користувача з видимим стиком, Issue #9. Чинні 512×512, ромб 128×64, anchor (64,32), zoom 1.2, туман/камера незмінні.

**Реалізовано в окремій гілці PR #10 (без merge):**
- `MapSurface.java`: для ВСІХ досліджених клітин видимої ділянки застосовується один набір PNG-текстур землі/моря; для процедурного світу поза 32×32 демо використовуються PNG гір, хвойних/листяних дерев, споруд; прибрано код геометричних трикутників/кіл і лінійних тайлів.
- Єдиний прохід slope/coast/river отримує сусідів через `terrainAt()`, у тому числі на межі demo/fallback; річковий маск за межами демо визначається сусідніми логічними річковими клітинами.
- Збережено viewport + halo, sprite Y-sort, bitmap LRU, непрозорий фіолетовий fog LAST та persist камери.
- Окремий тестовий пакет той самий `com.kopanka.maptest.stable`, `versionCode=6`, `versionName=0.3.2-world-png-preview`.

**Критерії Android-приймання:** PNG землю й дерева видно по ОБИДВА боки колишньої межі 32×32, жодних трикутників/кругів placeholders, немає систематичної ромбічної сітки, фіолетовий туман і камера лишилися правильними; оглянути стики узбережжя/річки, чіткість, Y-sort на телефоні. Виміряти FPS/RAM перед фінальним прийманням.

**Обмеження:** застосування одного пакета PNG по всьому світу НЕ означає, що художню географію 512×512 вже створено. `WorldMap.terrain()` за межами 32×32 залишається недопрацьованим процедурним джерелом: річки, гірські регіони, острови, берегові шви та природні переходи потребують окремого дизайну карти й QA. Арт v1.4 художньо не затверджено. Нова версія НЕ перевірена на фізичному Android — статус кандидата до CI/ручного тестування.

**Залежності та відкриті питання:** артдиректор має затвердити повний набір біомів/масок для всього світу, сформувати географічну схему та підтвердити природний вигляд. Розробник — перевірити pipeline build і передачу тестової APK; QA — надіслати скриншоти стиків і дані пристрою.
