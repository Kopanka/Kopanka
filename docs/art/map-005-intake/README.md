# MAP-005 — вхідний каталог погоджених арт-кандидатів

Ця папка призначена лише для **фактичної передачі бінарного ZIP** із восьми погоджених стилістично PNG, який згенеровано в робочому чаті.

**Очікувана назва файла:** `KOPANKA_MAP005_art_handoff.zip`

**Що має бути в ZIP:**
- `manifest.json` із SHA256 та повною геометрією 512×512 / 128×64 / (64,32) / 1.2×;
- `sprites/*.png`: 8 PNG (`slope_grass_01`, `slope_rock_01`, `riverbank_curve_01`, `coast_rock_01`, `mountain_range_01`, `ridge_low_01`, `natural_cave_02`, `forest_mix_01`);
- `macro_sprite_contact_sheet.png`, `scene_painterly_candidate.jpg`, `QA_REPORT.txt`.

### Чому ZIP відсутній
Бінарні PNG були створені у робочому чаті, але вони **не перебувають у GitHub**. Лише записати їхню назву або маніфест недостатньо. Не можна підтверджувати виробничу інтеграцію, доки точні байти не передано в репозиторій.

Після фізичного додавання ZIP до цієї папки [`map005-art-intake.yml`](https://github.com/Kopanka/Kopanka/blob/art/map-004-height-aware-preview/.github/workflows/map005-art-intake.yml) перевірить усі файли, прозорість, розміри і SHA256 та створить CI-артефакт для Android-розробки.

**Увага:** стилістику погоджено, але це великі художні **макрооб'єкти** (а не безшовні 128×64 клітини!). Інтеграція висотних/берегових стиків — окремий наступний блок. Уважно зберегти затверджений художній вигляд; не зменшувати ці PNG до 128×64 для імітації готових тайлів.
