# KOPANKA MAP-003 — v1.4 технічний кандидат (24.11.2026)

Пакет окремих PNG і редагованих SVG для Android. **Не фінально прийнятий артконтент**; відсутній тест на реальному Android і загальна художня відповідність ескізу не підтверджена. Від v1.3 додано контрольовані штрихи на скельних поверхнях, дрібні живописні акценти на кронах та механічні зразки зіткнення сусідніх річкових ребер, скрин контролю масштабу 1,2×.

- `prototype/android/app/src/main/assets/map/manifest.json` — schemaVersion=1, Android контракт.
- `prototype/android/app/src/main/assets/map/**.png` — окремі 62 PNG RGBA.
- `source_svg/` — 62 оригінальні редаговані SVG.
- `demo/map_32x32.json` — логічна географія, маршрут річки, об'єкти.
- `demo/map_32x32_full.png` — лише прев'ю, не тайл і не ігрова текстура.
- `demo/fixed_zoom_1p2x_desktop.png` — 1,2× комп'ютерний попередній перегляд (не Android).
- `demo/seam_edge_samples.json` — перевірка альфи у 4 опорних точках річкових ребер.

**Геометрія незмінна:** diamond 128×64, ground-anchor (64,32), camera 1,2×; 512×512 клітин світ; 32×32 демо. Шахта й печера зберігають попереднє художнє зменшення на 20%.

Правила: `N=1 E=2 S=4 W=8`, mask — побітова сума суміжних річкових ребер; берегові маски ті самі плюс кутові. Будь-яка модель чанків повинна визначати сусідів у глобальних координатах. Порядок рендеру ground > slope > water/coast > river > scenery > structure > opaque fog. Високі об'єкти сортувати за footprint Y. Для точного alpha bleed/extrusion та фільтрації пікселів потрібен Android тест. Не вводити героя, меню, ресурси або економіку.

**Не завантажено до GitHub**: ZIP потрібно перенести в окрему гілку до тестування CI. Проміжний арт не замінює затверджену ілюстрацію. Лише координатор приймає після перегляду й фізичного Android-тесту.
