# MAP-005 — Android 0.3.15: нерівні висотні грані (технічний кандидат)

Дата: 2026-11-28. **Статус: CI PASS; художня якість і фізичний Android-тест PENDING.**

## Мета та підстава
Після реального тестування Android 0.3.14 користувач повідомив: «Враження, що змінився масштаб. Остальне як і було». Скриншоти засвідчили довгі сіро-зелені смуги піднятих плит, стилістичний конфлікт деталізованих макроассетів із технічними горами й лісом, геометричні береги. Міняти лише колір неефективно. Потрібно замінити тип рендеру висотних граней, не змінюючи затверджений zoom.

## Вхід
- Оригінальні рішення `main/docs/DECISIONS.md`, світ **512×512**, ромб **128×64**, anchor **64,32**, **1,2×**, без обертання чи керування масштабом, збереження камери й відкритої території, туман графіт **#3B3F42**, обсяг «лише карта».
- `ElevationMap.java`: висотний крок **13 px**, 0–5 рівнів.
- `MapSurface.java` з Android 0.3.14.
- Чотири ART-macro PNG тесту 0.3.13 / 0.3.14 і скриншоти власника.

## Фактично створено

Малювання лише для перепадів висоти між дослідженими сусідніми клітинами. Окрема геометрія **не змінює** ізометричний footprint/zoom.

## Критерії приймання та обмеження
- На живому Android перевірити, що лінії на перепадах висот стали менш регулярними; вершини не обрізаються; fog не показує стінки невідкритих сусідів; камера реально 1,2×.
- Важливо: поточний модуль малює *технічні нерівні грані*, **не** природні artist-approved seamless 2,5D PNG. Верхні ромби все ще плоскі, стиль макроассетів і базової карти різниться, помітні світлі ромбічні основи нових об'єктів, річкові маски й узбережжя не завершені. Не заявляти, що художній MAP-005 готовий.
- Не робити багато послідовних інсталяцій через дрібні косметичні зміни. Цей APK — лише кандидат для наступного групового приймання. Не merge draft PR #10 до фізичної перевірки.
