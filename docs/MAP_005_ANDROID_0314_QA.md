## Відомі обмеження/відкриті питання
1. Автоматичні source tests і build НЕ доводять художню якість; чи справді схили виглядають природно, треба перевірити на телефоні.
2. Підставки нових деталізованих лісів, печери, хребта — **залишаються**: PNG містять власну художню основу; просте обрізання порушило б форму. Потрібні від художника бесшовні alpha-footprint/transition overlay для фактичного вигляду землі.
3. Стилістична неоднорідність між новими деталізованими об'єктами та старими спрощеними горами/деревами **залишається**. Зробити єдиний художній атлас у погодженому стилі — окрема залежність, не видавати `0.3.14` за фінальний MAP-005.
4. Гирло `Path mouth` випробуване кодом, але потребує візуальної перевірки берегової стиковки та маскування туманом на пристрої.
5. Немає фізичного FPS/RAM/теплового тестування. Draft PR #10 не merge до тесту власником.

## Критерії приймання для тестової APK
На Android порівняти ті самі гірську, річкову й прибережну ділянки, що на скриншотах 0.3.13. Підтвердити: зменшені довгі лінії, плавне й цілісне гирло, немає витоку рельєфу крізь fog, камера та explored state зберігаються. Окремо зафіксувати дефекти художнього підгону PNG без жодних нових ігрових механік.

## Незмінні параметри
Світ 512×512, ромб 128×64, anchor 64/32, фіксований zoom 1.2, графітовий туман, збереження камери/відкритої території; лише карта.
