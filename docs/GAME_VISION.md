# KOPANKA — бачення гри

Android-гра про дослідження світу, видобуток і розвиток поселення. Основний ігровий цикл: знайти ресурс → видобути → перевезти → переробити → продати або використати для будівництва. Дороги, склад, транспорт, виробництво і торгівля розвивають цей цикл.

Майбутня послідовність: карта → герой і пересування → видобуток/вантаж → дороги та доставка → переробка/торгівля → розвиток поселення. Підземний світ, союзи й протистояння залишаються ідеями для окремого проєктування.

Реклама, реферали та реальні виплати не входять до прототипу. Їхня економіка й відповідність правилам платформ потребують окремої перевірки до реалізації.

Історичні версії 0.7–2.4 є джерелом механік і візуальних референсів; поточні рішення наведені в `CURRENT_STAGE.md` та `DECISIONS.md`.
