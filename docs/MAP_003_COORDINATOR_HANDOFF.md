# MAP-001 / MAP-003 — пакет для рішення координатора

Дата підготовки: 2026-11-24. **Це пропозиція; не підписане та не затверджене рішення.**

## Мета
Закрити технічне погодження геометрії карти перед фактичним виробництвом і підключенням художніх ассетів. Єдине джерело прийнятих рішень — `main/docs/DECISIONS.md`.

## Що вже підтверджено
- Початковий затверджений обсяг у паспорті та `docs/CURRENT_STAGE.md`: тільки карта 512×512, ізометрія, 1,2×, без обертання й зуму, туман збереження.
- Android-розробник технічно погодив ромб 128×64, anchor (64,32), worldX=(col-row)×64, worldY=(col+row)×32, порядок ground→transitions→river→scenery→structures→fog. Посилання: Issue #4.
- Тестова Android-карта в draft PR #5 має працюючі камеру/туман за скриншотами користувача, а також окрему стабільно підписану тестову APK; не підтверджені виміри FPS/RAM, кінцеві PNG та всі seam cases.
- Draft PR #7 від PR #5 містить **неактивний** завантажувач PNG, JSON-перевірку й CI; повністю готової художньої карти ще немає.

## Дія координатора
1. Погодити або повернути геометрію MAP-001; внести реальну дату/статус/причину/наслідок/перевірку в `docs/DECISIONS.md` на основній гілці.
2. Окремо зафіксувати MAP-002A як «технічна основа перевірена на пристрої, артінтеграція та FPS/RAM відкриті» — без хибного «повністю прийнято».
3. Повідомити артдиректора через Issue #6, що можна передавати PNG; чат сам собою не надсилає повідомлення іншим чатам.

## Дія артдиректора після дозволу
В Issue #6 передати GitHub коміт/гілку з фактичними PNG, редагованими джерелами, `manifest.json`, авторськими правами, anchors, шарами, стиками води/річок і контрольною композицією 32×32.

## Дія розробника після передачі
Інтеграція PNG у renderer, безшовний рендер видимої ділянки, туман останнім шаром, роздільні bitmap assets і map model; нова APK лише після CI і реального пакету. Перевірка на телефоні: seams, географія, FPS/RAM, fog persistence, межі світу, модель пристрою.

## Коли потрібне втручання користувача
Один ключовий пункт — **підтвердження координатором геометрії MAP-001**; фінальні PNG потребують виконання роботи дизайн-роллю, а не ще одного встановлення APK. Поки ці два блокери відкриті, до телефону не торкаємося.
