## Обмеження: НЕ видавати це за завершену художню карту
1. Навіть ці кандидати — геометрично точні **технічні / художні експерименти**, не остаточний деталізований painterly стиль, схвалений власником. Не можна використовувати їх для фальшивої заяви «природний рельєф готовий».
2. Набір A працює лише для **elevation=0** і не містить діагональні берегові / скельні кути, острівні рифи, плавне дельтове гирло та окремі sea↔cliff переходи.
3. Набір B працює лише на видимих **E/S** гранях рівнів **1–2**. Кути, рівні 3–5, композиція з базовою землею і контури сусідніх боковин не проходили незалежний Android pixel-level тест.
4. Детальні макроспрайти лісів/печери/гори все ще мають помітні ромбічні підкладки. Художня уніфікація з базовою картою не виконана.
5. Android 0.3.15 з гілки `codex/map-003-android-png-integration` не змінювався цими арт-операціями. **Нова APK не зібрана**, фізичне тестування не проводилося.

## Передача в наступний блок
**Дизайн:** художньо довести 16 shoreline масок, рівні 1–5 E/S cliff faces, кути/діагоналі, берег річки з природним гирлом, узгодити alpha/ground для вже погоджених макрооб'єктів. Потрібні окремі PNG + редаговане джерело + manifest + таблиця стиків.

**Розробка Android:** інтегрувати лише прийнятий художній пакет у viewport renderer з LRU/alpha/Y-sort; порівняти pixel footprint **128×64×1,2** та 1.2-фіксацію камери; зберегти fog graphite `#3B3F42`, camera persistence та explored state.

**Критерій приймання:** природний цілісний 32×32 ландшафт без повторюваних смуг, підставок і розривів; потім **одна APK** і фізичний QA. Поки цей критерій **не досягнуто**, не просити власника встановлювати нову версію й не merge draft PR #10.

Жодного нового рішення про параметри карти не внесено: світ 512×512, 2,5D, 128×64, anchor(64,32), 1,2×, без обертання/зуму, лише карта.
