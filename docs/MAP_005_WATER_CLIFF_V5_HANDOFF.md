# MAP-005 · v5 — переходи піднятих берегів у воду

**Дата:** 2026-11-28  
**Статус:** **технічні кандидатні ассети, CI PASS; художня й Android-перевірка НЕ пройдені.**

## Мета
Зменшити ризик неприродного переходу вертикальних 2,5D схилів безпосередньо у воду. Підготувати окремі альфа PNG «скельна/трав'яна боковина + пінна лінія біля підніжжя». Не змінювати геометрію, туман чи тестовий Android рендер.

## Вхідні матеріали й обмеження
- Актуальний `main/docs/DECISIONS.md`: світ **512×512**, ізометричний ромб **128×64** при 1×, anchor **(64,32)**, зафіксована камера **1,2×**, без обертання, fog графіт **#3B3F42**, лише карта.
- `docs/art/map-005-height-faces/generate.py`: трав'яні та кам'янисті E/S боковини висот **1–5**, технічний крок **13 px на рівень**.
- `docs/MAP_005_TERRAIN_ART_V4_QA.md`: 136 раніше перевірених арт-кандидатів; усі mixed height/material ES ще **не** художньо прийняті.

Згенеровано кожну грань на базі вже наявної height-face геометрії, додано тонку нерівну прозору пінну лінію вздовж нижнього краю. ## Правила стикування
- Піднятий наземний сусід **E або S** з відкритою водою — кандидатний PNG `cliff_water_{side}_h{height}_{material}`.
- Намальований за одним правилом anchored `ground→water→cliff→scenery→opaque fog`. Високі об'єкти, shoreline та cliff відображати лише якщо досліджено відповідні клітини.
- Для грані water-cliff відмалювати **один** спец-ассет, **не накладати повторно** звичайну cliff face.
- Межі між двома cliff-water гранями різної висоти, діагональні water-edge та junction із річковим гирлом **не гарантовані безшовними**. Не активувати ці PNG як production tiles без pixel-level огляду.

## Критерії художнього приймання (ще не досягнуто)
- Скеля переходить у воду природно: немає видимих технічних вертикальних платформ чи повторюваних однакових смуг.
- Є природна дельта/гирло річки без окремого заокругленого кінчика.
- Підставки під cave, forest, ridge макроспрайтами не виділяються; простір має одну узгоджену деталізацію.
- Фінальна контрольна сцена 32×32 пройшла ручний арт-QA і потім одна Android APK — фізичний QA: туман, камера, межі, висотні стики та продуктивність.
- Жодних нових ігрових механік. Немає підстав зливати draft PR #10.

## Залежності й відкриті питання
1. Художні source assets в одному погодженому стилі; процедурні PNG самі по собі не досягають погодженого живописного результату.
2. Невирішені cliff-water кути, діагональні shore, з'єднання з річкою/морем і випадки високих сусідів.
3. Відсутній об'єктивний pixel-junction тест для PNG з різною прозорістю, хоча повна перевірка їхніх окремих файлів уже PASS.
4. Фінальні кадри з телефону для нової графіки неможливі, доки її не підключено до Android.
