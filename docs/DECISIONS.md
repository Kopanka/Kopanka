| 2026-11-24 | **Затверджено користувачем — MAP-001** | Геометрія карти: світ **512×512** логічних клітин; ізометричний ромб **128×64 px** у масштабі 1×; опорна точка клітини **anchor (64,32)**; фіксований масштаб камери **1,2×**; **без обертання** | Єдиний обов'язковий геометричний контракт для артдиректора й Android. Дозволено готувати відповідні ассети; саме це рішення **не означає** приймання художнього комплекту, FPS/RAM чи завершення MAP-002A/MAP-003. Підстава: явне підтвердження користувача 24.11.2026; попередня технічна звірка Android у Issue #4. Файли: `docs/DECISIONS.md`, посилання `docs/MAP_001.md`, Issue #4 та Issue #6. |

| 2026-11-26 | **Затверджено користувачем — позиція камери після перезапуску** | Після повторного запуску Android-карта відкривається на останній переглянутій ділянці, а не повертається до початкового району річки. Підстава: явне підтвердження користувача 26.11.2026 за результатами Android MAP-003 v0.3.0. Файли: `docs/DECISIONS.md`, `IsoCamera.java`, `MapSurface.java`; реалізація в draft PR #10, приймання на телефоні ще потрібне. |

Власник ще не приймав 0.3.5. |

| 2026-11-27 | **Затверджено користувачем — чорний туман війни** | Усі недосліджені клітини світу відображати повністю непрозорим чорним замість фіолетового; фон поза картою також чорний для однорідності | Затверджено прямою вказівкою «Увесь туман війни зробити чорним». Стан відкритих клітин, збереження туману й камери, 512×512, масштаб 1,2× незмінні. Зміни в `MapSurface.java`, `app/build.gradle` (кандидат 0.3.7) у draft PR #10. Файли: `MapSurface.java`, `app/build.gradle` у draft PR #10; збірка 0.3.8. Помилки краю висотного туману залишаються окремим завданням. |

| 2026-11-27 | **Затверджено користувачем — світліший графітовий туман** | Колір непрозорого туману війни та фону поза картою — **`#292D30`** замість попереднього графіту `#171B1D` | Підстава: скриншот Android 0.3.8, на якому попередній графіт виглядає майже чорним; після пропозиції світлішого `#292D30` власник відповів «Роби». Це **замінює** рішення про `#171B1D`, а не правило повного приховування недослідженого. Зміни: `MapSurface.java`, `app/build.gradle` у draft PR #10, тестова 0.3.9. Геометричні грані на краю fog виправляти окремо. |
